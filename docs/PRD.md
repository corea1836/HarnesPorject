# PRD: Shorts Scout

## 목표
유튜브 채널 하나를 분석해 "이 채널은 뭘 하고, 뭐가 뜨고, 어떤 롱폼을 쇼츠로 자르면 터질지"를 한 페이지로 보여준다.

## 사용자
채널의 롱폼 영상을 쇼츠로 재가공하려는 크리에이터·편집자. 로컬에서 실행한다.

## 사용 흐름
1. `.env.example`을 `.env.local`로 복사하고 채널 URL과 API 키 2개를 넣는다.
2. `npm run dev` 후 http://localhost:3000 을 연다.
3. 약 1분 동안 "분석 중" 화면이 보인 뒤 리포트가 뜬다. 새로고침하면 처음부터 다시 분석한다.
4. 다른 채널을 보려면 `.env.local`의 URL을 바꾸고 새로고침한다.

## 핵심 기능
1. **채널 개요**: 채널명, 구독자 수, 분석한 영상 수(최근 업로드 50개), 쇼츠 비중
2. **콘텐츠 요약** (OpenAI): 채널이 하는 콘텐츠 한 단락 + 주요 카테고리 3~6개
3. **뜨는 영상 Top 10** (지표): 평소 대비 배수 높은 순. 형식, 조회수, 일평균 조회수, 참여율 표시
4. **쇼츠 후보** (OpenAI): 롱폼 중 쇼츠로 자를 만한 영상 최대 6개. 추천 구간(설명란 챕터 기준, 없으면 "구간 정보 없음"), 훅 문구, 추천 이유, 점수(1~10), 해당 시점 유튜브 링크

## 지표 정의
- 일평균 조회수 = 조회수 / max(1, 업로드 후 경과 일수)
- 평소 대비 배수 = 조회수 / 같은 형식(롱폼·쇼츠) 영상들의 조회수 중앙값 (중앙값이 0이면 0)
- 참여율 = (좋아요 + 댓글) / 조회수 (조회수가 0이면 0)
- 쇼츠 판별 = 영상 길이 180초 이하

## MVP 제외 사항
- 입력 폼, 여러 채널 비교, 분석 기록 저장
- 캐시 (새로고침 = 재분석)
- 자막 분석, 영상 다운로드·자동 편집
- 썸네일 이미지, 정렬·필터 등 클라이언트 인터랙션
- 로그인, DB, 배포

## 디자인
- 도구처럼 보이는 단순한 한 페이지. 장식 없음
- 무채색 + 포인트 색 1개, 시스템 폰트
